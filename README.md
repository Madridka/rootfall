# Rootfall MVP

Realtime survival colony manager / settlement builder на Vue 3, TypeScript и Pinia.

## MVP-дизайн

Игрок вручную ставит каждую постройку на grid-карту 30x30, назначает роли жителям, добывает и перерабатывает ресурсы, переживает сезоны и заранее предупреждённые катастрофы. MVP проверяет не графику, а петлю:

1. выбрать цель;
2. найти или собрать нужный ресурс;
3. построить объект;
4. назначить подходящих жителей;
5. дождаться производства;
6. подготовиться к сезонному событию;
7. исследовать карту и открыть следующий технологический слой.

## Приоритет игровых систем

1. 100vh UI без глобального скролла: иначе игра не ощущается как управляемая стратегия.
2. Карта 30x30 со скрытыми клетками: генерация должна менять стартовые решения.
3. Ресурсы и строительство: база ручного контроля.
4. Жители и роли: игрок должен управлять приоритетами труда.
5. Game loop, время и сезоны: реалтайм создаёт давление.
6. Цели onboarding: игрок не гадает, чем заняться в первые минуты.
7. Производственные цепочки: дерево/еда/вода переходят в руду/металл/энергию/теплицу.
8. Катастрофы с предупреждением: честный рандом без хаоса.
9. Технологические открытия через цели: новые возможности создают новые зависимости.

## Архитектура

```text
src/
  components/
    GameMap.vue      # центральная grid-карта, выбор клетки, двойной клик
    LeftPanel.vue    # цели, события, предупреждения, состояние поселения
    RightPanel.vue   # постройки, выбранная клетка, жители и роли
    TopBar.vue       # ресурсы, день, сезон, скорость
  data/
    buildings.ts     # определения построек, стоимость, производство
    objectives.ts    # цепочка onboarding-целей
  stores/
    gameStore.ts     # Pinia store, game loop, экономика, события
  types/
    game.ts          # TypeScript-модели
```

## Основные модели

Ключевые интерфейсы находятся в `src/types/game.ts`: `GameTile`, `Resources`, `BuildingDefinition`, `Building`, `Resident`, `Objective`, `Disaster`.

## Псевдокод game loop

```ts
if speed === pause:
  return

repeat speed times:
  tick += 1
  build unfinished buildings by builder jobs
  run production for completed active buildings

  if day changed:
    consume food and water
    apply housing, heat, disaster effects
    update scheduled disaster warnings and active events
    spoil food when rain or fragileFood modifier is active

  evaluate active objectives
  unlock next objectives and rewards
```

## Реализованные MVP-системы

- 30x30 карта с типами `grass`, `forest`, `water`, `stone`, `ore`, `fertileSoil`, `swamp`, `ruins`.
- Скрытые области и ручное исследование радиуса вокруг выбранной клетки.
- Мировые модификаторы старта: мало дерева, далёкая вода, ранний холод и другие.
- Ресурсы: wood, food, water, stone, ore, fuel, metal, energy.
- Постройки из промта: жильё, склад, дорога, лесорубка, сборщик, колодец, костёр, шахта, плавильня, ветрогенератор, теплица.
- 5 стартовых жителей с параметрами здоровья, голода, жажды, энергии, настроения, роли и текущей задачи.
- Роли: builder, woodcutter, forager, waterCarrier, miner, smelter, farmer.
- Скорости времени: pause, x1, x2, x3.
- День 60 тиков, сезон 10 дней, цикл из четырёх сезонов.
- Катастрофы с предупреждениями: coldSnap, heavyRain/fog, drySeason.
- Цепочка из 24 onboarding-целей.
- Технологическое открытие шахты, плавильни, ветрогенератора и теплицы через цели.

## Roadmap

1. Баланс первых 20 минут: стоимость построек, скорость добычи, частота голода и жажды.
2. Очередь задач жителей вместо упрощённой обработки зданий.
3. Пути и влияние дорог на скорость доставки.
4. Общая вместимость склада вместо лимита на каждый ресурс отдельно.
5. Болезни, порча еды по месту хранения, перегруз шахты.
6. Расширенное исследование карты с экспедициями.
7. Сохранение и загрузка партии.
8. Метрики: время до первой воды, время до первого холода, дефициты ресурсов, простаивающие здания, завершение целей.

## Не делать в первой версии

- Боёвку и врагов.
- Сложную графику и анимации.
- Автоматическую застройку зон.
- Большие модальные окна для базовых действий.
- Сотни жителей и большие карты.
- Финальную победу, которая завершает игру.
